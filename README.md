## “三网直连”到底是什么意思？

“三网”通常指中国电信、中国联通、中国移动。

但“三网直连”并不是一个统一的技术标准，更不是看到商家写上“CN2”就代表三网全部精品线路。实际网络结构里，电信可能通过 CN2 GIA，联通可能通过 AS9929，移动可能通过 CMI、CMIN2 或其他优化路径。最终体验还会受到源站、目的地、访问运营商、时间段和具体路由调整影响。

DMIT 当前官网对网络的描述比较明确：

* **Premium Network**：使用包括自有骨干与中国电信 CN2 GIA 在内的优质传输，面向中国大陆及亚太访问质量。
* **Eyeball Network**：在 Tier 1 基础上增加针对中国大陆用户的优化线路，官网称其采用 CMIN2/CMI 等中国运营商网络。
* **Tier 1 Network**：主要追求亚太、北美和全球方向的带宽与路由效率，并不提供专门的中国大陆线路优化。

因此，如果你的搜索意图就是“**三网直连 VPS**”，真正需要优先看的通常是 Premium 或 Eyeball，而不是单纯看到“1Gbps”“10Gbps”就下单。

所以看到“三网直连”“CN2 GIA”“15ms”这类关键词时，正确的理解应该是：它说明了网络设计方向，不意味着全国所有用户、全天所有时间都固定得到同一个延迟。

## 套餐名称里那些代码，应该怎么读？

DMIT 的套餐名第一次看很容易让人产生“这是不是服务器内部型号”的错觉。

其实逻辑并不复杂。

`LAX` 是洛杉矶，`HKG` 是香港，`TYO` 是东京。

`Pro` 或官网现在使用的 **Premium Network**，代表中国大陆优化等级更高的网络系列；`EB` 对应 **Eyeball Network**；`T1` 就是 **Tier 1 Network**。

硬件平台则包括：

* **AN5**：AMD EPYC 9005 系列、Zen 5、DDR5、PCIe 5.0 NVMe。
* **AN4**：AMD EPYC 9004 系列、Zen 4。
* **AS3**：AMD EPYC 7003 系列、Zen 3。

官网把 AN5 定位为旗舰性能平台，AN4 定位为均衡型平台，AS3 则强调价格与每核心成本。

这也是为什么同样叫 MINI，不同线路、硬件组合价格可能完全不同。

## “大带宽”不等于“三网直连”

这是购买 VPS 时很容易踩的坑。

比如洛杉矶 T1 AN5 的部分套餐，10Gbps 端口、超高流量额度都非常漂亮，但 Tier 1 本身并不提供专门面向中国大陆的优化路径。

相反，Premium 某些套餐虽然价格高得多，但你的核心购买价值其实在网络，而不是单纯买到更多 GB。

所以如果你的需求是：

**国内访问网站、跨境 API、远程办公、游戏联机、媒体服务或其他对中国大陆访问稳定性敏感的业务**，应该优先比较 Premium 与 Eyeball 的线路，而不是只比较流量。

如果业务本身主要在北美、欧洲或亚太其他地区，国内用户只是少数访问者，Tier 1 可能就已经足够。

## 买三网直连 VPS，建议先看这四件事

### 先确认访问者在哪里

中国大陆用户为主，就优先研究中国优化线路。

美国用户为主，就不要因为一个“CN2 GIA”标签反而把服务器放到距离用户更远的地方。

网络方案始终要和访问者位置匹配。

### 再看线路，而不是先看 CPU

一个 4 vCore 的普通线路 VPS，未必比一个 2 vCore 的优化线路 VPS 更适合中国大陆用户。

尤其是在晚高峰，线路质量往往比多几核 CPU 更容易直接影响页面打开、SSH、API 请求和视频传输体验。

DMIT 当前部分 T1 产品直接使用 `Max (IN, OUT)` 标注双向流量额度，不能简单拿它和只统计出站流量的 VPS 做一对一比较。官网也说明，部分端口速度属于峰值指标，实际速度还受到 VM 性能及国际、本地网络环境影响。
